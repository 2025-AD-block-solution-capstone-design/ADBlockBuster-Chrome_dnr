데이터 저장 방식
업데이트된 룰셋이 브라우저 IndexedDB에 저장됩니다:
  • IndexedDB: 실제 룰셋 데이터 (용량 제한 없음)
  • Chrome Storage: 해시값, 날짜 등 메타데이터만 (10MB 제한)
  • 기존 룰셋 데이터는 업데이트 시 자동으로 교체됩니다
